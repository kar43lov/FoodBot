## Бриф: Персонализированные цели КБЖУ

**Цель:** Дать пользователям возможность задать физические параметры и цель (похудеть/набрать/поддержать), чтобы получать персонализированные нормы КБЖУ и рекомендации вместо одинаковых для всех.

**Выбранный подход:** Страница /profile в Web App + формула Mifflin-St Jeor + макро-сплит по цели

**Формулы:**
- BMR муж: `10×вес + 6.25×рост – 5×возраст + 5`
- BMR жен: `10×вес + 6.25×рост – 5×возраст – 161`
- TDEE = BMR × коэффициент (1.2 / 1.375 / 1.55 / 1.725)
- Цель: похудеть –500 ккал, набрать +300 ккал, поддержать = TDEE
- Макро-сплит: похудеть (Б30/У40/Ж30), поддержать (Б25/У55/Ж20), набрать (Б30/У45/Ж25)

**Требования:**

Функциональные:
1. Модель `UserGoal` в Prisma: sex, age, weight, height, activityLevel, goal, targetCalories, targetProtein, targetFat, targetCarbs
2. API: GET/PUT /profile/goals — чтение и сохранение целей
3. Web App: страница /profile с формой (пол, возраст, вес, рост, активность, цель) + preview рассчитанных норм
4. Бот: `getUserNorms(userId)` — возвращает персональные нормы или fallback на DAILY_NORMS
5. Бот: в /start и в отчётах подсказка «Настройте цели → Открыть приложение»
6. Рекомендации: передавать персональные нормы в generatePersonRecommendation()

Нефункциональные:
- Backward compat: без профиля — DAILY_NORMS
- TDEE рассчитывается на сервере при сохранении
- Данные приватные — каждый видит только свой профиль

**Acceptance criteria:**
- [ ] Пользователь может открыть /profile в Web App и заполнить 6 полей
- [ ] После сохранения видит рассчитанные нормы КБЖУ
- [ ] В отчётах /today используются персональные нормы (баланс ↑↓✓)
- [ ] AI-рекомендации учитывают персональные нормы
- [ ] Без заполненного профиля — работает как раньше (общие нормы)
- [ ] Бот подсказывает про возможность настроить цели

**Тестирование:**
- Unit: расчёт TDEE/макросов для разных входных данных
- API: GET/PUT /profile/goals — авторизация, валидация, CRUD
- Integration: getUserNorms с профилем и без
- Frontend: форма, валидация, preview норм

**Риски:**
- Нет критичных. Формула Mifflin-St Jeor — общепринятый стандарт

**Первые шаги:**
1. Модель UserGoal в Prisma (обе схемы) + миграция
2. Функция calculateTDEE() + тесты
3. API endpoint GET/PUT /profile/goals
4. React страница /profile с формой
5. Интеграция getUserNorms() в commands.ts

**Сложность:** medium
