# FoodBot Restart

Быстрый перезапуск systemd-сервиса `foodbot` без пересборки кода. Для применения изменений в `.env` или восстановления после зависания.

## Steps

1. Перезапустить сервис:

```bash
ssh karvpn "systemctl restart foodbot"
```

2. Подождать 3 секунды и проверить статус:

```bash
ssh karvpn "sleep 3 && systemctl is-active foodbot && curl -s http://localhost:3000/health && echo '' && journalctl -u foodbot --no-pager -n 10"
```

3. Показать пользователю:
   - Статус сервиса (active / failed)
   - Ответ health-endpoint
   - Последние 10 строк логов — проверить что стартап прошёл без ошибок

4. Если сервис `failed` — показать последние 20 строк логов и предложить откат:
```bash
ssh karvpn "journalctl -u foodbot --no-pager -n 20"
```

## Когда использовать

- Изменения в `.env` на сервере — нужно подхватить
- Бот завис / не отвечает, но процесс работает
- Проверка что старт проходит без ошибок (регресс после деплоя)

## Когда НЕ использовать

- Обновление кода — используй `/pg.foodbot.deploy`
- Откат — используй `git reset` + deploy

## Ограничения

- Разрешено: `Bash(ssh karvpn:*)`
- Только restart — никаких изменений кода или конфигов
